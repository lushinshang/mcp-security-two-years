## 200字介紹

MCP 當初設計授權流程時，預設電腦前有個人按下同意；這個假設在 agent 時代撐不住了。Den Delimarsky 以 MCP 維護者的身分回顧兩年來的安全工作：授權從各自發揮收斂到 OAuth、SDK 與一致性測試、部署中補上的逐一用戶端同意、受眾驗證與簽發者驗證，以及接下來要補的企業託管授權、DPoP、工作負載身分聯邦與 WAG。本導讀把講者的說法逐項對照官方規格與 IETF 文件：官方已穩定的標官方，仍在提案或個人草案的降級，講者自述的規模數字則註明沒有官方資料可核對。
